# 🃏 ポケモンカード価格監視・購入支援ツール (Pokemon Card Price Monitor)

ポケモンカードの複数ショップ（メルカリ、駿河屋、カードラッシュ、遊々亭、Amazon、トレトク等）の最安値・在庫状況を自動定期巡回し、目標価格に応じた通知・AI割安度診断を行うWebアプリケーションです。

---

## ✨ 主な機能

1. **📊 リアルタイム価格比較ダッシュボード**
   - 複数ショップの最新価格・在庫状況・最安値を一元表示。
   - 🎯 目標価格判定（「🎯 目標内」「⚠️ 目標外」「⏹ 該当なし」）。
   - 🤖 AI割安度診断機能。
2. **📱 PC / スマホ完全対応（表示モード切り替え機能）**
   - **💻 PC表示**: ワイド大画面データテーブル＆サイドバー固定。
   - **📱 スマホ表示**: 下部固定ボトムナビゲーション＆タッチしやすいカード型UI。
   - 画面幅による自動切り替えに加え、ヘッダーのトグルボタン（⚙️ 自動 / 💻 PC / 📱 スマホ）で自由に切り替え可能。
3. **⚡ 公式サイトからのセット名・カード番号（型番）一括自動補完**
   - ポケモンカード公式データベースと連携し、カード名からセット名やカード番号（例: `091/071 SAR`）を自動取得・補完。
4. **🛡️ 高精度抽出・ノイズ排除エンジン（Relevance Filter）**
   - 他TCG（ワンピース、遊戯王、デュエマ、MTG、ヴァイス等）を完全除外。
   - サプライ品（スリーブ、プレイマット、未開封BOX、オリパ、同人誌等）を自動除外。
   - 日本語単語境界判定（Word Boundary）により、「タロ」で「キタロウ」等の部分一致誤爆を完全に防止。
   - レアリティ・型番の厳密照合。
5. **⚙️ 抽出条件カスタマイズ機能**
   - グローバル設定（除外・必須キーワード、型番照合ポリシー）。
   - カード個別設定（カードごとの必須・除外ワード）。
   - リアルタイム抽出シミュレーター搭載。
6. **🔔 Web Push通知・アラート設定**
   - 目標価格以下になった際、または在庫が入荷した際にブラウザへ即時プッシュ通知。
7. **🔄 自動定期巡回＆手動巡回**
   - バックグラウンドでのタイマー巡回（5〜120分間隔）とワンクリック手動巡回。
   - 巡回完了時の自動画面リフレッシュ＆最終巡回日時の最新化。

## 🚀 クイックスタート（ローカル起動）

```bash
# 1. 依存関係のインストール
npm install

# 2. 初期データベース作成
node seed.js

# 3. サーバー起動
npm start
```
起動後、ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスしてください。

---

## 🌐 Web環境（クラウド）へのデプロイ方法

### 方法1: Render.com（無料ホスティング・推奨）
1. 本リポジトリを GitHub にプッシュします。
2. [Render.com](https://render.com/) にログインし、「**New +**」→「**Web Service**」を選択。
3. GitHub リポジトリを接続します。
4. 設定：
   - **Build Command**: `npm install && node seed.js`
   - **Start Command**: `npm start`
   - **Environment**: `Node`
5. 「**Create Web Service**」をクリックすると、数分でWeb上に公開されます。

### 方法2: Railway / Koyeb / Docker
- `Dockerfile` が含まれているため、GitHub リポジトリを Railway や Koyeb に連携するだけで自動的にビルド＆デプロイされます。
